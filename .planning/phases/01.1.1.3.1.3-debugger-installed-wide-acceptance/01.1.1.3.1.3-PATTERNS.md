**Source identity and cleanup** (`test/support/sweep_evidence.ex`, lines 45-73):

```elixir
def source_roots! do
  lane = lane!()
  evidence = load_archive!(@archive, @archive_sha)

  try do
    for {_lane, lock} <- evidence.manifest["locks"] do
      actual = read!(lock["path"]) |> digest()
      if actual != lock["sha256"], do: fail!(:lock_identity, lock["path"])
    end

    otp_lib = :code.lib_dir() |> to_string()

    otp_inventory = InstalledOtp.app_roots!(otp_lib, lane: lane.name)
    otp = Map.new(otp_inventory, &{&1.app, &1.root})

    elixir = Map.new(@elixir_apps, &{Atom.to_string(&1), &1 |> :code.lib_dir() |> to_string()})
    deps = Map.new(Mix.Project.deps_paths(), fn {app, path} -> {Atom.to_string(app), path} end)

    Map.merge(evidence, %{
      lane: lane,
      otp_inventory: otp_inventory,
      lock_sha256: evidence.manifest["locks"][lane.name]["sha256"],
      installed: otp |> Map.merge(elixir) |> Map.merge(deps)
    })
  rescue
    error ->
      File.rm_rf!(evidence.archive_root)
      reraise error, __STACKTRACE__
  end
end
```

Tests remove the extracted archive with `on_exit`, while the helper also cleans it if source resolution raises. These are static inventory/source checks; do not call debugger entry points or callbacks.

## Shared Patterns

### Exact lane and source binding

**Sources:** `test/contract/tier_sweep_test.exs` lines 5360-5366; `test/support/sweep_evidence.ex` lines 35-68; `test/support/installed_otp.ex` lines 592-661.  
**Apply to:** The aggregate contract.

Use the graph lane from `ctx.graph`, obtain fresh `SweepEvidence.source_roots!()` evidence, and pass the graph's current `receipt_lines` to the ownership validators. `InstalledOtp.verify_receipt_lines!/1` validates the receipt's lane, lock identity, rows, links, and footer digest.

### Ownership remains ledger-driven

**Source:** `test/support/debugger_settings.ex` lines 1275-1301 and 1308-1349.  
**Apply to:** The aggregate contract and any owner disposition it reports.

Reuse `DebuggerSettings.assert_ownership!/3`, `assert_receipt!/4`, and `assert_remainder_receipt!/4`. Keep inherited parent obligations and unresolved rows under their adopted owners; do not build a parallel map or promote a historical completion receipt.

### Static assertion failures

**Sources:** `test/contract/tier_sweep_test.exs` lines 5186-5217; `test/support/debugger_settings.ex` lines 1278-1299.  
**Apply to:** Negative controls for stale lane, receipt, source, or owner bindings.

Use `assert` for the contract and `assert_raise` around the existing validators for concrete mismatch controls. The aggregate is an offline source/BEAM acceptance check and must not claim runtime safety.
