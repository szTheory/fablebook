## Changed publication contract

Final core/floor inventories, observed projection, DELIVERY, and validation report are generated from the final exact successful PR-head run and remain workspace evidence. They record the tested code head and run, set `artifact_head` to null, and state that committing them would change the certified head. These artifacts are not committed to the PR. This replaces Plan 04's requirement that final exact-head receipts and DELIVERY be tracked in the same PR.

The collector and `verify-ci` continue to verify the live PR head, successful run, required checks/jobs, complete lane receipts, source/runtime/lock fingerprints, adopted authority, retained parent ownership, and review accounting. Workspace evidence does not count as a tracked artifact.

## Atomic evidence layout adjustment

The fixed-path sequence of per-file replacements did not preserve one complete prior evidence generation if collection stopped between replacements. The approved workspace-only publication contract now uses a contained immutable generation directory with the five named artifacts: core inventory, floor inventory, observed projection, full DELIVERY, and validation report. The collector validates all five files, then atomically replaces only the top-level `01.1.1.3.1.1-DELIVERY.json` pointer with the generation paths and SHA-256 digests. Until that pointer changes, the prior generation remains authoritative; an orphan new generation is ignored. No symlink is used. `verify-ci` and `verify-merged` resolve the pointer, verify every artifact digest, and independently re-fetch the same live PR/head/run/checks and complete lane logs.
