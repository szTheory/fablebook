## Negative controls and limits

The tagged audit rejects an empty record, an empty branch map, missing default/read-error branch identities, a missing function, wrong lane evidence, altered expected source text, a wrong source SHA, and an out-of-range line. The controls verify lane/MFA/owner/chain/remedy diagnostics. Function and export equality use both an independent installed BEAM scan and the existing graph; the three root identities must also match the effective ownership ledger and appear among fresh graph candidates.

The legacy tuple's literal `keep`, the current seven key names, and missing-key `proplists:get_value/2` behavior are recorded as source behavior only. Local `int:i/1` and global `int:ni/1` file restoration distinguish empty, one-file, and multiple-file inputs. Breakpoint status, enable/default action, custom action, tuple condition, and null condition remain separate branches.
