### Static-only guard probes

Compile generated fixtures to temporary BEAMs, inspect with BeamWalker, and run Credo against source. Keep dangerous calls inside uncalled function bodies; quoted code is a source-only control. The suite's `test "source-only fixtures raise a Credo issue and pass the BEAM walker (pinned)"` states the expected dual-layer distinction (lines 852–865). This establishes static detection only; it does not prove runtime atom safety or computed dispatch.

**Sources:** `docs/adr/0021-delivery-rules.md` lines 20–27 and the prior slice's tracked `01.1.1.2-VALIDATION.md` lines 50–61. For this guard-only slice, keep `lib/`, `.github/`, dependency and lockfile changes out of scope, use the focused existing command from the validation map, then require core `mix ci` and the existing floor compile/test commands on the exact PR head.
