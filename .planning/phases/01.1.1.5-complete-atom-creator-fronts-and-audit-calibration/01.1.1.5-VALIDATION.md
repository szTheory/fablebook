# Phase 01.1.1.5 — Validation Strategy

This strategy covers the transferred caller-text/file atom-creator fronts, all original identity preservation, a deliberately small representative semantic sample, and evidence-based sizing. It does not claim whole-table closure. Phase 01.1.1.1 owns the completed inventory/source-readiness evidence; Phase 01.1.1.4 owns every unsampled original row and complete semantic closure. SEC-01 remains assigned to Phase 5 for completion.

## Test Strategy

| Area | Validation boundary |
|---|---|
| Parser / caller-file front doors | Existing ExUnit source/BEAM contract tests with uncalled compile-only probes; do not invoke the dangerous API |
| Exclusion ledger | Exact original identity, provenance, count, owner, and replacement-set equality on both exact lanes |
| Representative calibration | Full matched-function-set equality, exact citations, caller-input traces, explicit semantic verdicts, and non-vacuous removal controls for selected CN/BD/EX rows |
| Source partitioning | Compare the evidence-based proposal against complete core/floor function sets and source sizes; do not cap matches or infer whole-table closure |
| Delivery | Contract-only diff, exact-head core and floor CI, required checks, and recorded run links |
| Budget handling | Treat 66k as a low-confidence projection, 80k as a review threshold and 100k as a planning ceiling. Execute one plan at a time without delegated agents; update estimates at plan boundaries and do not claim unmetered actual token use. These figures are not guaranteed caps. |

## Failure Direction and Prohibitions

- Inventory, source resolution, graph ingestion, missing debug information, and citation failures must fail closed with lane and affected identity; they must never become an empty success set.
- Removing a selected retained exclusion in memory must make its control fail; overlap must not make the control vacuous.
- Every runnable `<automated>` command in a plan must have an immediately following `<fails_when>` naming an observable failure.
- Never cap matched functions, invoke dangerous evaluator/loader/atom-creation APIs, fetch source during recurring tests, or convert unresolved Logger/ExUnit findings into exemptions.
- Stop if a newly judged front is already reached from `lib/`; preserve the exact MFA and caller trace and wait at the existing owner decision gate.
