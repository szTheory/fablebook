- **Broadening `:expansion`:** CN-004 overlaps `Elixir.Plug.Builder:compile/3`; investigate and trace the overlap under current policy without converting the category into blanket approval. [VERIFIED: `test/contract/tier_sweep_test.exs:11060-11077`]

## Common Pitfalls

### Pitfall 1: Mistaking local source for approved exact source

**What goes wrong:** A developer cites an installed source file even though its lane-specific manifest record is absent.
**Why it happens:** The resolver checks installed files, which can look sufficient on their own.
**How to avoid:** Add lane records for the exact source bytes and provenance first; the resolver requires a manifest row before it accepts installed/archive content. [VERIFIED: `test/support/sweep_evidence.ex:99-118,220-233`]
**Warning signs:** `SweepEvidence.resolve!/2` returns `:missing_source`, or a cited source digest does not match the manifest.

### Pitfall 2: Closing the source gap without completing caller provenance

**What goes wrong:** The implementation cites the main target and its delegate but leaves a caller's input construction or config mode unreviewed.
**Why it happens:** The primary target source already contains enough detail to make a plausible judgment.
**How to avoid:** CN-001 must bind `Mix.Compilers.Elixir.maybe_consolidate/4` and `elixir/lib/protocol.ex`; CN-004 must bind `Phoenix.Router.build_pipes/2` and `Phoenix.plug_init_mode/0`, in each applicable lane. Keep the verdict open if any required record is still missing/mismatched. [VERIFIED: `test/contract/tier_sweep_test.ex:1534-1540,10489-10499,11189-11208`]
**Warning signs:** `caller_citations` has an empty router entry, source gaps remain in the row, or a verdict is present without per-caller/delegate references.

### Pitfall 3: An unbounded first-row tracer

**What goes wrong:** Both rows are expanded before source ranges and review intervals establish a phase fit.
**Why it happens:** Each row has only one current matching function, which hides the caller/delegate source work.
**How to avoid:** Complete one row end-to-end first; measure source ranges and active review intervals, then decide whether the other row fits. The previous audit-budget gate explicitly says the byte/token proxy is not an execution schedule. [VERIFIED: `01.1.1.13-CONTEXT.md`; `01.1.1.1-AUDIT-BUDGET.md:28-39`]
**Warning signs:** Plan scope is sized from old whole-file bytes or historical bundles, without source-bound ranges and review observations.

### Pitfall 4: Vacuous or overlap-hidden removal proof

**What goes wrong:** The contract says a retained row matters but removal leaves all matches covered by another tier or exclusion.
**Why it happens:** CN-004's `compile/3` match currently overlaps the broad expansion matcher.
**How to avoid:** Compute the consequence of removing the individual row on each applicable lane and require a concrete uncovered match. Narrow/replace overlap only with original-to-current traceability; preserve the separate `.4` Macro/caller-AST scope. [VERIFIED: `test/contract/tier_sweep_test.ex:11211-11220`; `.planning/phases/01.1.1.4-complete-the-remaining-ban-list-semantic-audit-and-closure/01.1.1.4-CONTEXT.md`]
**Warning signs:** `removal_witness == []`, every recorded match remains covered after row removal, or the `:expansion` row is treated as a reason by itself.
