## Coverage granularity

| Option | Description | Selected |
|--------|-------------|----------|
| Whole-module bans | Simple, but broadly rejects benign debugger functions and loses route-level precision. | |
| Export-only MFA list | Easier to inventory, but can miss private paths and dynamic dispatch. | |
| Exact-lane function and branch dispositions | Review each installed function and risky branch with source and graph evidence; preserve benign functions. | ✓ |

**Selection basis:** Apply the recommended option per the owner’s auto-follow instruction.
**Notes:** Treat exports as an inventory baseline, not the full scope. Inspect source-only and unresolved dynamic apply / spawn paths because graph analysis alone can omit them.

## Trace and breakpoint route semantics

| Option | Description | Selected |
|--------|-------------|----------|
| Inert settings only | Treat saved callbacks and breakpoint conditions as data, without following their eventual dispatch. | |
| Static call-path evidence | Trace callback setters, storage, event gates, and dispatch without invoking the callback. | ✓ |
| Live debugger execution | Exercise callbacks and breakpoints in an integration test. | |

**Selection basis:** Apply the recommended option per the owner’s auto-follow instruction.
**Notes:** OTP documents that auto-attach invokes a configured callback through spawn/3 and conditional breakpoints call a configured function. Preserve the previous phase’s root and branch ownership; do not execute debugger code.

## Evidence standard

| Option | Description | Selected |
|--------|-------------|----------|
| Source-only review | Explains source branches but does not establish the installed function graph. | |
| BEAM graph only | Establishes installed functions and routes but does not explain source branch semantics or unresolved dynamic calls. | |
| Paired source, BEAM, ownership, and compile-only probe evidence | Combines exact-lane semantics and installed inventory with static guard controls; makes no runtime-safety claim. | ✓ |
| Live debugger integration tests | May demonstrate runtime behavior, but exercises callbacks and changes debugger/process state. | |

**Selection basis:** Apply the recommended option per the owner’s auto-follow instruction.
**Notes:** Use the approved OTP 27.3.4.9 and OTP 29.1.2 lane sources and installed BEAM evidence. Keep probes compile-only and use the existing guard patterns.
