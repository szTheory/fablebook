<objective>
Close the Phase 1 verification blocker CR-01 and its same-root-cause warning WR-03 in one contract-test-only PR. ADR 0004 is a non-negotiable: no atoms from input and no runtime eval or code loading. Today a one-line `lib/` change of the form `apply(String, :to_atom, [input])` passes `mix ci` on both lanes, because the BEAM guard's ban sets list only the Erlang BIF names that a direct call is inlined to. This plan grows the ban sets so that every literal dispatch form fails CI. It also brings the Credo layer to parity and makes the `mix.exs` text scan non-vacuous (WR-02).

Purpose: SEC-01's Phase 1 share (Phase 5 still owns the StreamData property and the mutation-proven tests). This plan extends D-23's atom and MFA tiers. It never narrows them, so it implements ADR 0004 rather than amending an owner-signed decision.
Output: one modified contract test, one modified Credo check and nine new negative fixtures, merged through one PR that touches no `lib/` or `.github/` file.
</objective>
