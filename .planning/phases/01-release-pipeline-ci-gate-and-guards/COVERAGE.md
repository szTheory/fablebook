No external API integration: the fablebook library ships no API client. This phase's only remote calls are release and CI tooling: `gh` and `curl` in `bin/ci_health`, `bin/smoke_consumer` and `hex-publish.yml` make fixed reads of GitHub REST (workflow runs, jobs, rulesets, issues) and hex.pm (release checksum, hexdocs), plus `mix hex.publish`. None of it is a product surface integrated into the library.
