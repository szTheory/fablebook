# Phase 01.1: Security

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| PR author → ban data and walker in `test/` | A weaker walker or tier lets a later `lib/` change pass CI | ban tiers, fixtures, `test/support/beam_walker.ex` |
| Request input → `lib/` | Input must never create atoms or reach eval, code loading or native loading (ADR 0004) | untrusted params |
| Repo write access → tag and branch refs | Only commits on main may be built and published (D-14) | tag name, same-named branches, moved tags |
| Build job → publish job | The commit and checksum the build verified must be the ones published | `needs.build.outputs.sha`, `SHA256` |
| `hex-production` environment → workflow steps | `HEX_API_KEY` reaches only the key-check and publish steps | `HEX_API_KEY` |
