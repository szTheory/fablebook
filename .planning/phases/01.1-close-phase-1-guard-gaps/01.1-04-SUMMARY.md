# Phase 01.1 Plan 04: Build, Publish and Smoke-Test the Tag's Own Commit Summary

**`hex-publish.yml` now checks out `refs/tags/<tag>`. Before any code from the tag runs, it resolves the tag to one commit, requires the checkout to be that commit and checks that the commit is on `main`. Every later job uses that commit. A package is published only when the rebuilt tarball's sha256 equals the build's, and any `todo` other than `package` or `docs` publishes nothing. Merged as PR #12.**
