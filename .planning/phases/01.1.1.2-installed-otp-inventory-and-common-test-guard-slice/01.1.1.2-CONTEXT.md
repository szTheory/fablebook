## Implementation Decisions

The prior CONTEXT decisions D-01–D-14, adopted SPLIT, current ROADMAP and verification policy already settle the consequential choices. Their relevant portions are carried forward here. No interactive question was needed: implementation mechanics remain delegated, and this capture does not infer new approvals from silence.

### Independent installation inventory

- Discover the actual OTP installation on each lane, including applications pruned from Mix's active code path and applications that have not started. Loaded applications, a fixed app count and the existing `@otp_apps` filter cannot define completeness. Retain Elixir application coverage and the production dependency closure derived from project metadata. (Prior D-04.)
- Pin evidence to core Elixir 1.20.4 / OTP 29.1.2 and floor Elixir 1.18.5 / OTP 27.3.4.9. Record actual application versions, discovered BEAM identities, source availability, function/match counts and source bytes per lane. Local results and exact-lane CI receipts are separate evidence. (Prior D-09; SPLIT.)
- Keep discovered inventory, successfully inspected inventory and active disposition coverage distinct. Discovery/inspection must account for the complete installation; pending semantic audit is an explicit transfer, never a safe exclusion or evidence that the complete guard sweep passes. Existing live sweep coverage cannot shrink. (SPLIT; current phase SC1/SC3.)
- Unreadable files, failed Xref ingestion, absent debug information and missing required source analysis must be observable and fatal. An empty result cannot stand in for a failed scan. Omission and synthetic-installation controls must demonstrate rejection. Inspect applications without starting GUI/debugger/Common Test apps or invoking dangerous APIs. (Prior D-05.)

### Common Test caller-file/load path

- Follow the actual exported caller-file/load path in exact-lane source. `:ct_make.files(files, [:load])` is the existing concrete detection gap. Judge caller influence and reachable behavior rather than function names; cover wrappers reached within this bounded family. Research establishes the exact exports and traces before planning their dispositions. (Prior D-01–D-04.)
- Mirror unsafe fronts in Credo and the BEAM contract, with uncalled direct/capture/apply/generated probes and relevant source-only forms. StrictCtMake must report hits in both layers. Preserve benign controls and existing conservative atom bans. Compiling and inspecting a fixture proves static detection, never runtime atom safety. (Prior D-02/D-03.)
- Changed exclusions require substantive cited triples, full changed-family match mappings and an independent nonvacuous removal witness for each retained exclusion on each applicable lane. Preserve original identities. Lane absence requires inventory/export evidence. Do not broaden this into the remaining exclusion audit. (Prior D-06–D-08.)

### Source evidence and bounded delivery

- Reuse the approved exact-version source resolver/archive, lock provenance, digest/containment/line checks and offline recurring tests. Inspect source availability across the expanded inventory; the existing archive is not proof that every newly discovered source is present. Report an unavailable prerequisite and propose a compliant resolution during research rather than silently claiming source coverage. The existing archive approval is not a new unlimited storage or network budget. (Prior D-09; INT-20261030-01; SPLIT.)
- Start with at most two bounded PR slices, subject to research calibration; this is the inherited split's planning target, not an executable plan. Every phase remains at most five plans/about three working days; each plan has 2–3 tasks, at most five files per task and projected executor context at most 100,000 of 200,000 tokens. Partition by actual module/function/caller chain and measured cost, never row count alone. Split newly reached work before exceeding the budget. Phase structure is already delegated. (SPLIT; INT-20261029-02; ADR 0021.)
- Reuse one graph per lane, existing ExUnit/Xref/BeamWalker/Credo infrastructure and small helpers. No new dependency, general audit/taint framework, recurring network fetch, application starts or stale cross-toolchain cache. Keep runtime and mutation backstops with Phase 5. (Prior D-03/D-14; SPLIT.)
- Scoped guard PRs remain separate from `lib/`, `.github/`, dependency, lockfile and `.credo.exs` changes. Each merges only with unchanged checks green and exact tested CI links. Preserve the ordinary two-review-pass cap; the prior phase's one-off extra pass does not renew this phase's budget. (Prior D-13; ADR 0021; INT-20261030-03.)

### Existing safety stops and command boundaries

- A newly banned `lib/` caller stops affected implementation with its exact MFA, callsite, caller-input trace and triggering guard. Only the owner may select the ADR-backed allowlist or separate-library-PR remedy. Independent work may proceed without claiming closure. (Prior D-11.)
- Macro caller-AST classification remains an owner decision in the substantive AST family of 01.1.1.4. Changed Credo explanation wording remains an owner checkpoint in 01.1.1.5. Neither is resolved or brought forward here. (Prior D-10/D-12.)
- Automate observable acceptance within the requested step and reuse prior evidence for unchanged behavior. Do not require repeated confirmation to preserve an existing stop. GSD auto-advance stays disabled; this discussion ends with the research/planning command. (AGENTS.md; verification policy; INT-20261029-05.)

## Existing Code Insights

### Reusable Assets

- `SweepEvidence` validates exact runtime/lock/archive identity, resolves installed or archived sources and checks containment/digests/lines.
- The sweep builds forward/reverse graph data once in `setup_all`, derives production dependency closure from project metadata and already has source-family/removal controls.
- The ban contract has generated per-tier probes, direct/capture/apply/source-only patterns and an existing uncalled StrictCtMake fixture.

### Established Patterns

- Source and BEAM detection complement one another; preserve their documented static limitations and benign controls.
- Semantic truth comes from source review; automation checks source identity, coverage, schema and removal witnesses.
- Existing graph coupling must be investigated before activating new disposition coverage. If a family cannot merge independently, split the coupled path together or stop that concrete slice; no exemption may hide a red result.

### Integration Points and Observed Gaps

- `@otp_apps` currently filters installation discovery to named applications. `out_of_scope/0` reports omissions but does not establish full installed coverage.
- `build_graph/0` calls `:xref.add_directory/2` without validating each result. The expanded inventory must account for successful ingestion explicitly.
- Debug-form extraction records failures; preserve and extend fatal coverage rather than treating failed files as empty graphs.
- StrictCtMake's BEAM expectation is currently `[]`, and the Credo strictness sample for `:ct_make.files(files, [:load])` currently expects `false`. Both must become positive detection after the exact-source disposition.
- The current source archive was built for earlier bounded families. Complete installed source availability and budget remain unmeasured here.
