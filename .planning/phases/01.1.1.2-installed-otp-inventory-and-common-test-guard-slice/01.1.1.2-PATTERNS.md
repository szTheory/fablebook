### test/support/beam_walker.ex (utility, transform)

**Analog:** test/support/beam_walker.ex

Use this parser for BEAM identities, source metadata, imported MFAs and debug forms. It reads BEAM chunks without loading the inspected module, and represents absent or unreadable debug data as an error rather than an empty scan.

**Core parse and error pattern** (lines 4-34):

    case :beam_lib.chunks(path, [:debug_info]) do
      {:ok, {_module, [debug_info: {:debug_info_v1, _backend, :none}]}} ->
        {:error, :no_debug_info}

      {:ok, {module, [debug_info: {:debug_info_v1, backend, data}]}} ->
        with {:ok, forms} <- backend.debug_info(:erlang_v1, module, data, []) do
          {:ok, {^module, [imports: imports, compile_info: info]}} =
            :beam_lib.chunks(path, [:imports, :compile_info])
          code = function_code(forms)
          {:ok,
           %{
             module: module,
             source: to_string(info[:source]),
             atoms: atoms(forms, MapSet.new()),
             mfas: imports,
             pairs: pairs(code, MapSet.new()),
             literals: literals(code, MapSet.new())
           }}
        end

      {:error, :beam_lib, {:missing_chunk, _, _}} -> {:error, :no_debug_info}
      {:error, :beam_lib, reason} -> {:error, reason}
    end

scan/1 currently returns module, source, atoms, MFAs, adjacent pairs and literals (lines 18-26). If inventory needs function-form totals, extend that returned scan result while retaining the __info__/1 exclusion in function_code/1 (lines 37-38); do not use module loading or turn scan errors into zero counts.

      |> Enum.reject(fn {m, f, _} -> m in [:erlang, :erl_eval, :erl_ddll] or f == :module_info end)

## Shared Patterns

### Inventory and inspection fail closed

**Sources:** test/support/sweep_evidence.ex:4-9,43-69,81-99; test/support/beam_walker.ex:4-34  
Use lane/app/module-specific evidence and explicit errors. Do not represent missing roots, no-debug BEAMs, unreadable source, failed Xref ingestion or set mismatches as empty results.

### One graph; independent discovery

**Source:** test/contract/tier_sweep_test.exs:1969-1972,2618-2653  
Retain one Xref graph per lane and the existing Elixir-app and production dependency closure. Discover OTP apps/BEAMs from the installation filesystem independently, then compare identities across discovery, BeamWalker inspection and Xref ingestion.

### Mirror Credo and BEAM guard data

**Sources:** credo/checks/banned_calls.ex:73-115,369-403; test/contract/banned_calls_test.exs:65-115,1015-1068  
Keep the source matcher and @mfa_tier in sync. Generated probes and explicit benign/source-only controls prove static detection boundaries, not runtime safety.

### Preserve source evidence invariants

**Sources:** test/support/sweep_evidence.ex:72-99,124-160,185-215; test/contract/tier_sweep_test.exs:2330-2465  
Use the exact lane archive/manifest resolver, temporary tampering controls and offline recurring checks. The archive is not an unlimited source cache.
