## Sampling Rate

- After each guard/helper change: run its focused contract tests, then the focused command above before committing.
- Before merging each scoped PR: existing required CI checks must pass at the tested revision on both supported lanes; preserve the existing allowed-skip rule and record run links.
- After each plan: run the applicable full lane gate. Reuse unchanged evidence only as allowed by .planning/VERIFICATION.md.
- Use one Xref graph per lane/run and small pure negative controls for fast feedback. Do not assert a sub-30-second full sweep without measurement; isolate quick helper checks from the full inventory sweep if needed.
- Every runnable automated verification in PLAN.md must have an immediately following `fails_when` describing an observable failure signal.
