## Shared Patterns

Keep both because their detection boundaries differ; tests explicitly assert source-only fixtures raise Credo issues while compiling to no BEAM hits (`test/contract/banned_calls_test.exs:517–531`). Neither is the runtime atom-count property owned by Phase 5.

### Positive probes and negative controls

Dangerous calls remain in uncalled fixture bodies. Pair each new positive result with a benign negative control and keep the generated MFA probe check nonvacuous. The current strictness rows for PathConsult/CtMake are no-hit outcomes and must be updated before claiming the new behavior.

### Fail closed with lane-specific evidence

The current graph already uses ExUnit `setup_all` data, Xref exports/edges, BEAM abstract forms and call-chain diagnostics. Extend that contract with discovered-versus-scanned set equality, asserted Xref ingestion, and explicit debug-info/citation errors. Do not add a dependency or recurring network source fetch; local exact CI lane source roots remain unresolved in RESEARCH.md:178–187 and must be proven before calling citation resolution complete.
