## Why this replan exists

These facts support a precise no-candidate result while GSR-03/GSR-05 remain open.

## Execution feedback — exact lane invocation

The local core CI command must match the GitHub job environment: `.github/workflows/ci.yml` sets `MIX_ENV=test`, while `bin/lane <lane> mix` defaults to `dev` unless the variable is supplied. Therefore the valid local command is `MIX_ENV=test bin/lane core mix ci`. A run without that prefix is an invocation mismatch and cannot stand in for the CI test result. The core test-shape contract now checks that Mix 1.20 ignores `test/support/*.ex` despite the project’s custom ignore filters.
