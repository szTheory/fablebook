## Sampling Rate

- **After every task commit:** quick run command (plus the sweep command once it exists) and `mix credo --strict`
- **After every plan (before push):** `mix ci` on the latest lane, then the floor lane command
- **Before `/gsd-verify-work`:** CI `core`, `floor`, `dialyzer`, `security` and `ci-gate` green on every merged PR, with run links recorded
- **Max feedback latency:** 15 seconds
- **Mutation controls:** each plan adds a temporary `lib/` probe that must turn the guard red, records the failure line, and reverts it without committing
