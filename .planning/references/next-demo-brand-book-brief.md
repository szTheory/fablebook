# Next fictional app brand book: recommendation

This is an implementation-informed recommendation, not an owner decision or a roadmap change. Provenance: the owner's request during guard Phase 1, docs/research/TWINS.md, references/PRODUCT-ROADMAP.md and the existing Logistify intake/book. These Books and the import contract remain planned.

1. **Chatly first, then Clinicly.** The roadmap groups them before Finanza and Shopadelic. Chatly adds Japanese/CJK, emoji, mobile messaging, large counts and disconnected cases beyond Logistify's freight tables and forms.
2. **Show Chatly's inbox, conversation and members.** Include empty/one/many conversations; huge unread counts; long Japanese group names; one-to-one/group threads; long mixed Japanese/Latin/emoji messages; missing avatars; sending, failed send and retry; loading, unavailable, offline and reconnecting. Show dark and light at phone and desktop widths, keyboard focus and enlarged text. Notification denial is optional if notifications are in scope. Tables are not essential for this app.
3. **Supply structured tokens and contrast pairs; SVG logos/icons with small/light/dark cuts; fonts and license files; voice, terminology and realistic copy; consistent fictional people, conversations and messages with stable IDs.** These need deliberate mapping: no finished Fablebook importer/export schema is claimed.
4. **Logistify was useful.** Its layouts and empty/loading/error/many/long examples provide strong reference material. The remaining build inputs are reusable fictional records, stable persona/job/case IDs, and connected examples such as failed shipment → reassignment → result. These are requests for scenario material, not claims that the app or coverage map is implemented.

Use invented data only. Preserve the distinction between drawn reference layouts and implemented UI. The priority above does not prevent the owner from choosing Finanza next.
