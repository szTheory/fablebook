**Compile helper** (lines 2098-2113):

```elixir
defp compile!(files, dir, debug_info) do
  previous = Code.get_compiler_option(:debug_info)
  Code.put_compiler_option(:debug_info, debug_info)

  {result, _stderr} =
    try do
      ExUnit.CaptureIO.with_io(:stderr, fn ->
        Kernel.ParallelCompiler.compile_to_path(files, dir)
      end)
    after
      Code.put_compiler_option(:debug_info, previous)
    end

  assert {:ok, modules, _warnings} = result
  Enum.map(modules, &Path.join(dir, "#{&1}.beam"))
end
```

This helper compiles fixtures to temporary BEAM files and restores the compiler option in `after`; it does not call their functions. No new fixture should invoke an evaluator, parser, loader, or atom-creation API.

```elixir
def scan(beam_path) do
  path = to_charlist(beam_path)

  case :beam_lib.chunks(path, [:debug_info]) do
    {:ok, {_module, [debug_info: {:debug_info_v1, _backend, :none}]}} ->
      {:error, :no_debug_info}

    {:ok, {module, [debug_info: {:debug_info_v1, backend, data}]}} ->
      scan_debug_info(path, module, backend, data)
```

The walker reports compiled imports, functions, edges, and literals while rejecting missing debug info. Continue using it as a read-only contract helper; do not add runtime invocation to make a probe observable.
