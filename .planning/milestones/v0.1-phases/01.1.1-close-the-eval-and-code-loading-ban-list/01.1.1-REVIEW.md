## Narrative Findings (AI reviewer)

### CR-01: [BLOCKER] Absolute Elixir qualification is rewritten through local aliases

**File:** `credo/checks/banned_calls.ex:451-453`  
**Severity:** BLOCKER  
**Issue:** `module_name/2` strips the `Elixir.` prefix and then applies the local alias map. Elixir treats an explicit `Elixir.Module` as an absolute root-module reference, even when the current scope has `alias String, as: Module`. With that alias in scope, a macro containing `quote(do: Elixir.Module.concat(unquote(parts)))` is interpreted by the checker as `String.concat`, so Credo reports no issue. The compiled macro contains the quoted alias syntax as data rather than a `Module.concat/1` call, so `BeamWalker` also reports no hit. A targeted reproduction confirmed both checks return no finding while Elixir resolves the reference to `Module.concat/1`; when expanded with caller-controlled strings, it can create atoms.

**Fix:** Preserve whether the AST starts with `Elixir` and bypass alias expansion for absolute names. Add a source-only fixture with a used `alias String, as: Module` and the quoted `Elixir.Module.concat/1` call; require Credo to flag it while pinning that the compiled-BEAM walker remains blind to the quoted call.
