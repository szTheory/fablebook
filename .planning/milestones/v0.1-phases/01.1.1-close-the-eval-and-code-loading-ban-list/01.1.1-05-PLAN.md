AST shapes (research Pattern 4, verified with `Code.string_to_quoted!`):
- quoted call: `quote(do: Module.concat(unquote(x)))` holds `{{:., _, [{:__aliases__, _, [:Module]}, :concat]}, _, args}` inside `{:quote, _, [[do: ...]]}`.
- alias: `alias Module, as: M` → `{:alias, _, [{:__aliases__, _, [:Module]}, [as: {:__aliases__, _, [:M]}]]}`; `alias :file, as: F` → `{:alias, _, [:file, [as: ...]]}`; multi-alias `alias Foo.{Bar, Baz}` → `{:alias, _, [{{:., _, [{:__aliases__, _, [:Foo]}, :{}]}, _, [...]}]}`; `require M, as: X` aliases too.
- newline after the dot (`Module.\nconcat([x])`) parses to the same remote call.
- `apply(Module, :concat, [x])` → `{:apply, _, [{:__aliases__, _, [:Module]}, :concat, [...]]}`.
- `x |> Module.concat()` has an argument list one shorter, so match `{m, f}` regardless of arity.
- `Elixir.Module.concat(x)` → aliases head `:Elixir`; `:"Elixir.Module".concat(x)` → a plain atom.
- `%{:erlang => :load_module}` → `{:%{}, _, [erlang: :load_module]}`; `{:erlang, :load_module, a}` → `{:{}, _, [:erlang, :load_module, a]}`.
- `Macro.prewalk` (used by `Credo.Code.prewalk/3`) visits list literals and 2-tuples but not a call's argument list as a whole: check adjacency on each `{form, meta, args}` argument list explicitly, and return the `{:., _, [m, f]}` dot node without its function-name leaf so call names are never treated as data (SC3 at source level).
