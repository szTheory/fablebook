### Exact-lane source evidence and fail-closed resolution

**Source:** `test/support/sweep_evidence.ex` (tracked helper; lines 28-73, 99-118, 220-249).  
**Apply to:** any new per-lane audit record, source citation, or lane-absence claim.

```elixir
def lane!(runtime) do
  name = if System.get_env("FABLEBOOK_FLOOR") in [nil, ""], do: "core", else: "floor"
  expected = %{elixir: hd(@refs[name]["elixir"]), otp: hd(@refs[name]["otp"])}

  if runtime != expected,
    do: fail!(:runtime_identity, %{lane: name, expected: expected, actual: runtime})

  Map.put(runtime, :name, name)
end

def resolve!(evidence, citation) do
  {relative, line} = parse_citation!(citation)
  row = source_record!(evidence, relative, citation)
  {path, root, origin} = source_file!(evidence, row, relative, citation)
  path = realpath!(path)
  root = realpath!(root)
  if not String.starts_with?(path, root <> "/"), do: fail!(:source_escape, citation)
  data = read!(path)
  if digest(data) != row["sha256"], do: fail!(:source_digest, {citation, origin})
  ...
end
```

`test/support/installed_otp.ex` is the companion for inventory parity and required-source checks: its `assert_discovery_complete!/3` compares all discovered app/BEAM identities (lines 146-188), and `source_app!/5` rejects missing required source (849-883). Reuse these exact-lane inventories and resolvers; do not create a second source index or merge core/floor evidence.
