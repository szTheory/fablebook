## Phase Goal

**As a** developer, **I want to** open the local catalog and inspect a short dispatcher flow, **so that** I can revisit its screens in the host environment while production excludes them.

<objective>
Build the real local Phoenix host and trace one supported dispatcher Scenario from the public mount through the catalog, browser pipeline and inherited Canvas. Build against the exact source and the previously verified production boundary.
</objective>

This slice owns 13 files. The isolated Mix project, lock, config, endpoint, ExUnit bootstrap and two local assets are needed to run the host. The literal router, compiled Story, catalog, LiveView, fixed Book and focused test establish the mounted path. Each task touches at most five files. The later delivery plan reuses the host configuration and loading hook.
